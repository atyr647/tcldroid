# upstream

- `versions.env` — the single source of truth for pinned Tcl, Tk and NDK inputs and their checksums.
- `patches/` — our patch series against pristine upstream. `tools/fetch-upstream.sh` applies `tcl.series` / `tk.series` (one patch filename per line, `#` comments allowed) after unpacking. Keep patches small, one concern each, in the shape an upstream reviewer would accept.

Current patches (applied in order by `tools/fetch-upstream.sh`, listed in `patches/tk.series`; regenerated by `tools/upstream/make_series.py`, see [docs/upstream-submission.md](../docs/upstream-submission.md)):

- `0001` `generic/tkPort.h`: `TK_ANDROID`, include `tkAndroidPort.h`.
- `0002` the platform-header selection sites in `generic/` (`tkEvent.c`, `tkCmds.c`, `tkBind.c`, `tkPointer.c`, `tkWindow.c`, `tkGrab` ... and `default.h`).
- `0003` `generic/tkWindow.c`: destroy every window explicitly on Android.
- `0004` `library/tk.tcl`: load the Android touch policy.

`series/` is the *submission* form: the same four plus `0005`, which adds the `android/` directory and the Android scripts. `tools/upstream/verify_series.sh` proves the submission equals the tested tree.

Tcl itself needs **no patches**: unmodified Tcl 9.0.4 cross-builds and runs on Android (see docs/status.md). New (non-patch) Tk files live in `tk-android/android/` and are copied into the Tk tree by `tools/fetch-upstream.sh`.
